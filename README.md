# Assignment 4: Forms and Validation

Student: Kamila Ahmadzada
Group: (SE-2530)

Website for the Web Technologies assignment on forms. Each task has its own page and the navbar links them all.

## Pages

- index.html: home page
- task0-contact.html: simple contact form
- task1-validation.html: contact form with HTML5 validation
- task2-bootstrap.html: contact form with Bootstrap classes and grid
- task3-bootstrap-validation.html: Bootstrap validation styles (is-valid, is-invalid)
- task4-registration.html: registration form

## How to run

Open index.html in a browser. Bootstrap loads from a CDN, so you need an internet connection.
